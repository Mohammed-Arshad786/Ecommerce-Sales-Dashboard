# Ecommerce-Sales-Dashboard
Interactive Sales Ai Dashboard

📊 **My AI-Assisted Interactive Sales Dashboard Project**

📊 Project Overview

This project focuses on analyzing sales data and presenting business insights through an interactive dashboard.

I worked with a sales dataset containing approximately 30,000 records. Microsoft Excel was used for the initial data analysis, KPI preparation and visualizations. AI assistance was then used to help develop an interactive web-based dashboard.

I'm happy to share a sales performance dashboard project that I created with the assistance of ChatGPT.

**Project Features:**
- Monthly sales performance
- Sales by product category
- Regional sales analysis
- Order status analysis
- Payment method analysis
- KPI cards and interactive filters
- Upload sales data using a JSON file

📈 Excel Analysis

Microsoft Excel was used during the initial analysis process.
Worked with the sales dataset.
Prepared important KPIs such as Total Sales and Total Orders.
Created sales visualizations.
Explored monthly sales performance.
Analyzed sales by category, region and order status.

## 🗂️ Sample Data Format

The dashboard reads a JSON file that contains a list of orders. Each order looks like this:

```json
[
  {
    "order_id": "ORD-0001",
    "order_date": "2023-04-12",
    "category": "Home & Kitchen",
    "region": "South",
    "status": "Delivered",
    "payment_method": "UPI",
    "quantity": 3,
    "discount": 350.00,
    "total_amount": 5200.50
  }
]
```
A ready-made file is included in this repository: `sample-data.json`. Download it and use **Upload JSON file** to try the dashboard.
⚠️ Update the field names above to match the ones your index.html actually reads. A small sample-data.json is included so you can try the dashboard right away.
